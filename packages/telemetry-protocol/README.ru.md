# @ft/telemetry-protocol

[English](README.md) · **Русский**

Декодер UDP-пакета «Data Out» из Forza Horizon 6: 324 байта, та же раскладка, что у Forza Horizon 4 и 5. Пакет не использует API Node.js и DOM, поэтому его могут использовать и API, и браузер, и React Native.

```ts
import { decodePacket } from '@ft/telemetry-protocol';

const result = decodePacket(datagram);
if (result.ok) {
  render(result.packet.speed, result.packet.gear);
}
```

| Экспорт                                                        | Назначение                                                                                                                                                                                                                    |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `decodePacket(bytes)`                                          | `{ ok: true, packet }` или `{ ok: false, error }`. На UDP-порт может прийти что угодно, поэтому некорректная датаграмма — это значение, а не исключение.                                                                      |
| `TelemetryPacket`                                              | По одному числу на каждое задокументированное поле; имена как в официальной документации (camelCase), единицы и кодировки как в протоколе: скорость в м/с, `isRaceOn` — 0 или 1. Интерпретация значений — задача потребителя. |
| `PACKET_FIELDS`                                                | Таблица полей в порядке следования в пакете. Она построчно повторяет официальный список; смещения (`FIELD_OFFSETS`, `PACKET_LAYOUT`) вычисляются из неё.                                                                      |
| `encodePacket(fields)`                                         | Собирает датаграмму; незаданные поля равны нулю. Для тестов и симуляторов.                                                                                                                                                    |
| `carClassOf()`, `drivetrainOf()`, `gearOf()`                   | Смысл кодированных полей: буквы классов FH6, FWD/RWD/AWD и передачи как −1 для заднего хода, 0 для нейтрали, 1… вперёд.                                                                                                       |
| `DEFAULT_TELEMETRY_PORT`, `RESERVED_PORTS`, `isReservedPort()` | Порт проекта по умолчанию и диапазон, который занимает сама игра (5200–5300).                                                                                                                                                 |

## Тесты

- Пакеты, записанные из игры ([`test/fixtures`](test/fixtures)), фиксируют то, что документация оставляет открытым: единицы, кодировку передач, нулевые пакеты вне езды, поля круга на границе кругов.
- Смещения сверяются со значениями, выписанными вручную из документации, независимо от таблицы полей.
- Каждое поле проходит через `encodePacket` и `decodePacket` с уникальным ненулевым значением, поэтому поле, прочитанное по чужому смещению, тест не пройдёт.
- View на часть большего буфера декодируется правильно; `Buffer` в Node часто именно такой view.

Описание полей, источники и открытые вопросы: [docs/fh6-data-out.ru.md](../../docs/fh6-data-out.ru.md).
