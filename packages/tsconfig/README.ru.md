# @ft/tsconfig

[English](README.md) · **Русский**

Общие конфигурации TypeScript.

| Конфиг         | Для чего                                                                                                                                                             |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `library.json` | Платформенно-независимые пакеты, которые используют Node, браузеры и React Native. Глобальных типов Node и DOM нет, поэтому `Buffer` или `window` не скомпилируются. |
| `node.json`    | Сервисы и CLI на Node.js (с `@types/node`).                                                                                                                          |

`base.json` строже, чем просто `strict: true` (`exactOptionalPropertyTypes`, `noUncheckedIndexedAccess`, …), и не предназначен для прямого наследования.

## Разрешение внутренних пакетов

Библиотеки workspace отдают исходники TypeScript под условием экспорта `@ft/source`, которое каждый конфиг включает через `customConditions`:

```json
"exports": {
  ".": {
    "@ft/source": "./src/index.ts",
    "default": "./dist/index.js"
  }
}
```

Проверка типов, линт, тесты и навигация в редакторе читают исходники напрямую, поэтому им не нужна предварительная сборка зависимостей. Потребители во время выполнения, которые не знают этого условия (обычный Node), получают скомпилированный `dist`.
