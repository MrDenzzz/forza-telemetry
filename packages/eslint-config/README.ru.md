# @ft/eslint-config

[English](README.md) · **Русский**

Общие flat-конфиги ESLint: строгие и стилистические правила `typescript-eslint`, использующие типы; форматирование остаётся за Prettier.

```js
// eslint.config.js
import { node } from '@ft/eslint-config';

export default node(import.meta.dirname);
```

| Экспорт | Для чего                                                                                                                                   |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `base`  | Платформенно-независимые библиотеки.                                                                                                       |
| `node`  | Сервисы и библиотеки на Node.js (добавляет глобальные имена Node).                                                                         |
| `cli`   | Утилиты командной строки: `node` с разрешённым выводом в консоль.                                                                          |
| `react` | React в вебе и в React Native: `@eslint-react` и правила React Hooks. `eslint-plugin-react` не используется: он не поддерживает ESLint 10. |

Конфиги сделаны фабриками, потому что правилам, использующим типы, нужен каталог пакета-потребителя, чтобы найти его `tsconfig.json`.
