# @ft/replayer

[English](README.md) · **Русский**

Отправляет запись по UDP с исходным таймингом, поэтому всё, что стоит дальше по цепочке, ведёт себя так, будто запущена игра.

```sh
# из корня репозитория
pnpm replay recordings/fh6-2026-10-02T14-44-40.ftr.gz --loop
```

| Параметр           | По умолчанию | Значение                                               |
| ------------------ | ------------ | ------------------------------------------------------ |
| `--host <address>` | `127.0.0.1`  | Адрес назначения                                       |
| `--port <number>`  | `9876`       | Порт назначения                                        |
| `--speed <number>` | `1`          | Скорость воспроизведения, например `2` — вдвое быстрее |
| `--loop`           |              | Начинать заново после конца, пока не нажат Ctrl+C      |

Тайминг обеспечивает `replay()` из [`@ft/recording`](../../packages/recording/README.ru.md): время отправки отсчитывается от начала каждого прохода, поэтому гранулярность таймеров Windows не накапливается в дрейф.
