# @ft/recorder

[English](README.md) · **Русский**

Записывает UDP-поток «Data Out» из игры в файл байт в байт вместе со временем прихода. Сохраняется каждая датаграмма, в том числе та, что не является пакетом Horizon.

```sh
# из корня репозитория
pnpm record --note "Goliath, 3 круга"
```

В игре: Settings → HUD and Gameplay → Data Out **On**, IP **127.0.0.1**, порт **9876**. Версиям из Microsoft Store нужно [исключение для loopback](../../docs/fh6-data-out.ru.md#настройка-сети-в-windows).

| Параметр                | По умолчанию                           | Значение                                                         |
| ----------------------- | -------------------------------------- | ---------------------------------------------------------------- |
| `--port <number>`       | `9876`                                 | UDP-порт для приёма; 5200–5300 отклоняются, их занимает игра     |
| `--host <address>`      | `127.0.0.1`                            | `0.0.0.0` принимает пакеты с консоли или другого компьютера      |
| `--out <path>`          | `recordings/<game>-<timestamp>.ftr.gz` | Файл записи; `.gz` сжимается                                     |
| `--game <fh6\|fh5>`     | `fh6`                                  | Сохраняется в метаданных: по самому пакету игры не различить     |
| `--note <text>`         |                                        | Сохраняется в метаданных                                         |
| `--forward <host:port>` |                                        | Дополнительно пересылать каждый пакет, например в запущенный API |
| `--duration <seconds>`  |                                        | Остановиться автоматически                                       |

Раз в секунду выводит число принятых пакетов, текущую частоту, долю пакетов с `IsRaceOn` и объём данных. Ctrl+C сбрасывает и закрывает файл; если вместо этого убить процесс, файл `.gz` может оказаться обрезанным.

Каталог `recordings/` игнорируется git. Записи, которые служат фикстурами тестов, копируются в тестируемый пакет.
