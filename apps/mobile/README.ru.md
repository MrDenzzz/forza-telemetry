# @ft/mobile

[English](README.md) · **Русский**

Приложение на Expo, которое превращает телефон в горизонтальный дашборд для игры: тахометр со скоростью и передачей, газ и тормоз, диаграмма перегрузок со следом за 1,5 секунды, температура и сцепление шин и время кругов в гонках. Оно подключается к API по локальной сети и само переподключается.

## Запуск

На телефоне нужен [Expo Go](https://expo.dev/go) для **SDK 57** (на iOS Expo Go просит войти в аккаунт Expo), а сам телефон должен быть в той же сети Wi-Fi, что и компьютер.

```sh
pnpm --filter @ft/api db:local      # один раз за сеанс, см. корневой README
pnpm dev                            # API на :4000, по умолчанию слушает локальную сеть
pnpm --filter @ft/mobile start      # в другом терминале: отсканировать QR-код в Expo Go
pnpm replay <запись> --loop         # без игры
```

Первый экран спрашивает адрес API и предлагает компьютер, с которого загружено приложение: обычно API работает на нём же. Адрес запоминается, кнопка **Change** в строке статуса возвращает к этому экрану.

Приложение только для Android и iOS: если открыть `localhost:8081` в браузере, там будет манифест для Expo Go, а не приложение.

Если телефон не подключается:

- **Брандмауэр Windows.** Когда Node.js впервые начинает слушать сеть, Windows спрашивает, разрешить ли ему это. Разрешите для частных сетей или откройте входящие TCP-порты 8081 (сборщик) и 4000 (API).
- **QR-кода нет или он не открывается.** Введите в Expo Go адрес `exp://<IP компьютера>:8081`; IP показывает `ipconfig`.
- **Гостевой или офисный Wi-Fi.** Некоторые сети изолируют клиентов друг от друга, и тогда телефон вообще не видит компьютер.

## Как устроен рендеринг

Кадры приходят до 30 раз в секунду. Как и в вебе ([ADR 0004](../../docs/adr/0004-live-dashboard-rendering.ru.md)), числа берутся через `useFrameValue` и перерисовываются только при изменении показываемого значения. Графика не перерисовывается вовсе: кадры записываются в shared values Reanimated, а их на UI-потоке читают тахометр и диаграмма перегрузок (Skia) и полосы педалей и сцепления (стили Reanimated). Стрелка тахометра плавно идёт между показаниями, поэтому движется гладко на экранах 60 и 120 Гц. Подробности и альтернативы: [ADR 0007](../../docs/adr/0007-mobile-app.ru.md).

Подключение, store, тексты статусов, правила отображения и геометрия перегрузок берутся из [`@ft/live-client`](../../packages/live-client/README.ru.md), общего с веб-дашбордом.

Что ещё делает приложение:

- Когда приложение уходит в фон, сокет закрывается, а при возврате открывается снова.
- Экран не гаснет, пока идёт езда.
- Приборы тускнеют, когда показывают последний кадр, а не живой поток.
- Работают обе горизонтальные ориентации.

## Структура

```
src/
  app.tsx            экраны: загрузка сохранённого адреса, подключение, дашборд
  connect/           ввод адреса API, подсказка и хранение
  live/              дашборд, приборы, хуки shared values, геометрия тахометра
  theme.ts           палитра веб-дашборда
```

Metro читает пакеты монорепо из их исходников на TypeScript через условие экспорта `@ft/source` ([metro.config.js](metro.config.js)), как это делают тесты API и инструменты.

## Тесты

Jest с `jest-expo` и React Native Testing Library — связка, которую поддерживает Expo; остальной репозиторий тестируется на Vitest. Тесты проигрывают скриптованный поток из `@ft/live-client/testing`:

- **Поведение:** состояния подключения, показания, шины, время кругов и закрытие потока в фоне.
- **Работа с адресом:** ввод, подсказка и хранение.
- **Геометрия тахометра** в виде обычных чисел.

Нативный модуль Skia заменён заглушкой, Reanimated работает на JS-потоке.

`pnpm --filter @ft/mobile build` собирает бандлы для Android и iOS через `expo export`. CI запускает эту сборку, поэтому модуль, который Metro не может найти, роняет сборку.
