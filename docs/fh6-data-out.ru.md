# Справочник по «Data Out» Forza Horizon 6

[English](fh6-data-out.md) · **Русский**

Всё, что проект знает о потоке телеметрии игры: что говорит официальная документация, что наши записи подтвердили или опровергли и что ещё остаётся открытым.

## Транспорт

| Свойство           | Значение                                                                                                                                                         | Источник                   |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| Протокол           | Односторонний UDP, игра ничего не читает из сокета                                                                                                               | Официально [1]             |
| Размер пакета      | 324 байта, один фиксированный формат (выбора Sled/Dash, как в Forza Motorsport, нет)                                                                             | Официально [1], записи [8] |
| Частота            | Равна частоте кадров игры: при 75–85 FPS записано 72–86 пакетов/с                                                                                                | Официально [1], записи [8] |
| Когда отправляется | **Непрерывно.** По документации — только во время езды; на деле в меню, при загрузке, перемотке и на экране результатов приходят нулевые пакеты с `IsRaceOn = 0` | Опровергнуто записями [8]  |
| Адресат            | Любой IPv4-адрес, включая `127.0.0.1`                                                                                                                            | Официально [1], записи [8] |
| Запрещённые порты  | 5200–5300: в этом диапазоне игра открывает собственный исходящий сокет                                                                                           | Официально [1]             |
| Порядок байт       | Little-endian                                                                                                                                                    | Записи [8], парсеры [3–5]  |
| Настройки в игре   | Settings → HUD and Gameplay → Data Out, Data Out IP Address, Data Out IP Port                                                                                    | Официально [1]             |

Что из этого следует для кода:

- Частота зависит от FPS и плавает (медианный интервал между пакетами 11,5–13,5 мс, 95-й перцентиль до 16,5 мс), поэтому даунсэмплинг, агрегаты и тайминг воспроизведения считаются по времени, а не по количеству пакетов.
- Пакет с `IsRaceOn = 0` означает «игра запущена, но игрок не едет». Тишина означает, что игра закрыта, Data Out выключен или идёт загрузка: при загрузке наблюдались паузы до 1,1 с.
- `TimestampMS` растёт шагами по 15–16 мс (разница между соседними пакетами 0, 15 или 16) и переполняется примерно через 49,7 суток, поэтому для тайминга он слишком груб. Вместо него используется время прихода пакета.

## Раскладка пакета

Смещения вычислены по упорядоченному списку полей из официальной документации [1]. Поля колёс идут группами по четыре в порядке: переднее левое, переднее правое, заднее левое, заднее правое.

| Смещение | Группа               | Поля                                                                                                                                                                                                       |
| -------- | -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0–19     | Состояние, двигатель | `IsRaceOn` S32, `TimestampMS` U32, `EngineMaxRpm`, `EngineIdleRpm`, `CurrentEngineRpm` F32                                                                                                                 |
| 20–67    | Динамика             | `Acceleration` XYZ, `Velocity` XYZ (локальные оси машины: X вправо, Y вверх, Z вперёд), `AngularVelocity` XYZ (рад/с), `Yaw`, `Pitch`, `Roll` (рад)                                                        |
| 68–211   | Колёса ×4            | `NormalizedSuspensionTravel`, `TireSlipRatio`, `WheelRotationSpeed` (рад/с), `WheelOnRumbleStrip` S32, `WheelInPuddle` S32, `SurfaceRumble`, `TireSlipAngle`, `TireCombinedSlip`, `SuspensionTravelMeters` |
| 212–231  | Машина               | `CarOrdinal`, `CarClass` (официально 0 = D … 7 = X, см. открытые вопросы), `CarPerformanceIndex` (100–999), `DrivetrainType` (0 FWD, 1 RWD, 2 AWD), `NumCylinders`                                         |
| 232–243  | Только в Horizon     | `CarGroup` U32, `SmashableVelDiff` F32 (м/с), `SmashableMass` F32 (кг)                                                                                                                                     |
| 244–311  | Dash                 | `Position` XYZ (м), `Speed` (м/с), `Power` (Вт), `Torque` (Н·м), `TireTemp` ×4, `Boost` (psi), `Fuel` (0–1), `DistanceTraveled` (м), `BestLap`, `LastLap`, `CurrentLap`, `CurrentRaceTime` (с)             |
| 312–322  | Гонка, ввод          | `LapNumber` U16, `RacePosition` U8, `Accel`, `Brake`, `Clutch`, `HandBrake` U8 (0–255), `Gear` U8, `Steer` S8 (−127…127), `NormalizedDrivingLine` S8, `NormalizedAIBrakeDifference` S8                     |
| 323      | —                    | Один завершающий байт, не задокументирован                                                                                                                                                                 |

Поля без явно указанного типа — F32. 88 задокументированных полей занимают 323 байта.

### Сравнение с другими играми

- **Forza Horizon 4 и 5** используют ту же раскладку на 324 байта. Парсеры сообщества считали байты 232–243 неизвестными и пропускали их (`data[:232] + data[244:323]` в [3]); FH6 — первая игра, где они задокументированы. По размеру пакета эти игры не различить, поэтому игра записывается в метаданные, а не определяется автоматически.
- **Forza Motorsport (2023)**: формат «Dash» занимает 331 байт [2]. В нём нет блока Horizon на смещении 232, зато в конце есть `TireWear` ×4 и `TrackOrdinal`. **Данных об износе шин в FH6 нет.**

## Подтверждено записями

Четыре сессии, записанные 2026-10-02 (FH6 в Steam, все помощники включены): свободная езда, кольцевая гонка на два круга с перемоткой, спринт и смена машины. 49 811 пакетов, из них 37 605 во время езды [8].

| Вопрос                      | Результат                                                                                                                                                                                    |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Единица `TireTemp`          | Фаренгейты. Значения лежат в диапазоне 50–347, а в начале сессии составляют 96–106; 347 °C для дорожной шины невозможны, а 347 °F (175 °C) после дрифта правдоподобны. Официально не указано |
| Температура задних шин      | `TireTempRearLeft` равна `TireTempRearRight` в каждом пакете езды у всех четырёх машин, а передние различаются. Скорее всего, это баг игры: заднюю ось стоит считать одним значением         |
| `Acceleration`              | м/с² в локальных осях машины, без гравитации: у стоящей машины ровно 0, а изменение скорости во времени совпадает с `AccelerationZ` (отношение 0,91–0,97)                                    |
| `Gear`                      | 0 — задний ход (видно при движении назад), 1–7 — передачи вперёд, 11 — нейтраль (отдельные кадры при переключениях автомата и на месте)                                                      |
| `WheelInPuddle`             | Целочисленный флаг 0 или 1, как сказано в документации FH6 (Forza Motorsport на этом смещении отдаёт глубину во float)                                                                       |
| Завершающий байт            | Всегда 0                                                                                                                                                                                     |
| `Fuel`                      | Всегда 1: в Horizon нет расхода топлива                                                                                                                                                      |
| Меню паузы в свободной езде | Поток не прерывается, `IsRaceOn` остаётся 1                                                                                                                                                  |

### Жизненный цикл гонки

Наблюдалось в кольцевой гонке и в спринте:

1. **Свободная езда:** `RacePosition`, `LapNumber`, `CurrentLap` и `DistanceTraveled` равны 0. `CurrentRaceTime` считает время езды и продолжает счёт после захода в меню и смены машины.
2. **Старт:** `IsRaceOn` становится 1, `CurrentRaceTime` — 0, а `RacePosition` — номеру позиции на старте. `DistanceTraveled` начинается с отрицательного значения (−112 м, −41 м): машина стартует позади линии старта.
3. **Пересечение линии старта** в кольцевой гонке сбрасывает `CurrentLap` примерно через 4 с, а `LapNumber` остаётся 0. Здесь начинается хронометраж круга; это не завершённый круг. В спринте `CurrentLap` всё время равен `CurrentRaceTime`.
4. **Круг завершён:** `LapNumber` увеличивается, `LastLap` и `BestLap` обновляются в том же пакете, а `CurrentLap` сбрасывается.
5. **Финиш:** для последнего круга `LastLap` не обновляется. `IsRaceOn` падает в 0, и все поля обнуляются. Время последнего круга — это `CurrentLap` из последнего пакета езды (71,51 с), а итоговый `DistanceTraveled` (11 902 м) равен двум длинам круга (5 950 м).
6. **Перемотка:** начинается точно так же, как финиш, — нулевыми пакетами на всё время перемотки (3,8 с). Затем `IsRaceOn` возвращается, `CurrentRaceTime` оказывается примерно на 2 с раньше (74,61 → 72,66), а круг тот же.

Что из этого следует для определения сессий и кругов:

- `RacePosition > 0` отличает гонку от свободной езды; смена `CarOrdinal` начинает новую сессию.
- Круг завершён, когда увеличивается `LapNumber`. Сброс `CurrentLap` без этого — линия старта.
- Конец гонки достоверен только тогда, когда езда не возобновилась за отведённое время, потому что перемотка в начале выглядит так же. Последний круг тогда берётся из последнего значения `CurrentLap`.

## Открытые вопросы

| Вопрос                                     | Что известно                                                                                          | Как выяснить                                    |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| Буквы `CarClass`                           | Наблюдались 2 при PI 600, 4 при PI 711 и 6 при PI 960 и 998, что не совпадает с границами классов FH5 | Посмотреть в игре класс этих машин              |
| Гонка, брошенная посреди круга             | Должна выглядеть как финиш с коротким последним кругом                                                | Записать гонку, брошенную на середине           |
| Механическая коробка, сцепление, поребрики | Все записи сделаны на автомате с помощниками; `WheelOnRumbleStrip` ни разу не срабатывал              | Записать без помощников на трассе с поребриками |

## Настройка сети в Windows

- **Steam:** работает с `127.0.0.1` без дополнительной настройки. Для трафика через loopback правило брандмауэра не нужно.
- **Microsoft Store / PC Game Pass:** игра работает в AppContainer, и Windows по умолчанию блокирует её трафик на loopback [6]. Исключение добавляется один раз из консоли с правами администратора:

  ```powershell
  # Найти имя семейства пакета (в именах пакетов нет слова "Forza")
  Get-AppxPackage | Where-Object Name -match '624F8B84B80|ForteBaseGame' | Select-Object Name, PackageFamilyName

  CheckNetIsolation.exe LoopbackExempt -a -n=<PackageFamilyName>   # добавить
  CheckNetIsolation.exe LoopbackExempt -s                          # список
  CheckNetIsolation.exe LoopbackExempt -d -n=<PackageFamilyName>   # удалить
  ```

  Известные имена: FH5 `Microsoft.624F8B84B80_8wekyb3d8bbwe` (несколько независимых источников), FH6 `Microsoft.ForteBaseGame_8wekyb3d8bbwe` (только сообщения сообщества [7]). В этом проекте такой сценарий не проверялся.

- **Другой компьютер или Xbox:** отправлять на LAN-адрес приёмника и разрешить UDP-порт в брандмауэре приёмника.
