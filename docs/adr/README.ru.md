# Архитектурные решения (ADR)

[English](README.md) · **Русский**

Короткие записи решений, которые определяют устройство кода: контекст, выбор и его цена.

| ADR                                        | Решение                                   | Статус  |
| ------------------------------------------ | ----------------------------------------- | ------- |
| [0001](0001-monorepo-pnpm-turborepo.ru.md) | Монорепо на pnpm workspaces и Turborepo   | Принято |
| [0002](0002-recording-format.ru.md)        | Сырые бинарные записи со временем прихода | Принято |

Новая запись повторяет структуру существующих: Контекст, Решение, Последствия, Рассмотренные альтернативы. Устаревшая запись остаётся на месте со ссылкой на ту, что её заменила.
